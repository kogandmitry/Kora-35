# КОРА 35 — монитор проекта

Первый релиз визуального монитора проекта КОРА 35.

## Что внутри

- `index.html` — статическое приложение.
- `data/kora35-monitor.json` — первый структурированный снимок данных.
- `src/` — валидация данных, модель, рендеринг и браузерная логика.
- `tests/` — тесты на контракт данных и видимость по ролям.

## Запуск

```powershell
cd 08_МОНИТОР
npm test
npm run validate
npm run serve
```

Открыть: `http://localhost:4173`.

## Границы первого релиза

Это статический монитор. Он не хранит пароли, токены, персональные данные детей/родителей и чувствительные финансовые детали. GitHub/static-публикация предназначена только для безопасного прототипа.

## Hero-видео

Первый релиз использует CSS-заставку без внешних медиафайлов, чтобы не было битых ссылок. Когда будет готово видео, положить файлы в `assets/hero/` и подключить в `index.html`:

- `kora35-wellbeing-loop.mp4`
- `kora35-wellbeing-poster.png`

## Деплой

Временная публикация описана в `docs/github-static-deploy.md`.

Боевой контур должен быть перенесен на российский VPS с HTTPS, PostgreSQL, авторизацией и бэкапами.
