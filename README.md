# КОРА 35 — монитор проекта

Две постоянно действующие версии визуального монитора проекта КОРА 35.

## Что внутри

- `index.html` — точка выбора аудитории.
- `org/index.html` — рабочая версия орггруппы: задачи, роли и организационный контур без подробного бюджета.
- `customer/index.html` — управленческая версия заказчиков с подробным public-safe бюджетом.
- `data/kora35-monitor.json` — первый структурированный снимок данных.
- `data/kora35-budget.json` — источник строк общего бюджета юбилейного проекта: выезд, предъюбилейные события, управление, премии, инфраструктура, основные, деактивированные/неутверждённые оценённые и неоценённые позиции.
- `src/` — валидация данных, модель, рендеринг и браузерная логика.
- `tests/` — тесты на контракт данных и видимость по ролям.

## Запуск

```powershell
cd 08_МОНИТОР
npm test
npm run validate
npm run serve
```

Открыть:

- `http://localhost:4173/org/`
- `http://localhost:4173/customer/`

## Границы первого релиза

Это статический публичный монитор. Он не хранит пароли, токены, персональные данные детей/родителей и чувствительные финансовые детали. Разделение аудиторий управляет представлением, но не является авторизацией.

Правило обязательного обновления двух версий закреплено в `MONITOR_SYNC_POLICY.md` и `AGENTS.md`.

## Hero-видео

Первый релиз использует CSS-заставку без внешних медиафайлов, чтобы не было битых ссылок. Когда будет готово видео, положить файлы в `assets/hero/` и подключить в `index.html`:

- `kora35-wellbeing-loop.mp4`
- `kora35-wellbeing-poster.png`
